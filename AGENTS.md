# Artwork update rules

- Put every newly supplied gallery image ahead of all previously added artwork. Prepend new batches to NEW_ARTWORK; preserve the artist's supplied order within each batch.
- Keep My art at 12 images per page and four columns, using the existing masonry presentation.
- Do not duplicate an artwork when a new supplied version replaces an older copy; show the new version at the front.
- Home page sample replacements also belong in My art. Keep the replaced examples in the gallery unless the artist asks to remove them.
- Images 2.png and 3.png from the 2026-11-04 batch must display on white, including in dark mode. Use CSS surfaces so original PNG transparency remains intact.
- Optimize newly supplied artwork for display before publishing: use JPEG previews up to 900 pixels on the longest side at quality 82, matching the existing gallery; composite transparent artwork on white. Point gallery and home samples to these previews and preserve original source files.
